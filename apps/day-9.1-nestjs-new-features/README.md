# Day 9.1 - NestJS New Features

This module explores new features and capabilities in NestJS.

## Getting Started

```bash
# Install dependencies
pnpm install

# Run in development mode
pnpm start:dev

# Run in production mode
pnpm start:prod
```

## API Documentation

Swagger documentation is available at: `http://localhost:3000/api`

## Topics Covered

- New features in NestJS
- Best practices
- Advanced patterns
